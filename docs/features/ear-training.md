# 听力训练设计

## 音程听辨

- 系统随机生成根音和目标音程。
- 支持上行、下行、随机方向。
- 用户可选择哪些音程类型进入训练题库；当前题和答案选项都来自已选音程池。
- 两个音依次播放。
- 用户从常见音程中选择答案。
- 首版覆盖纯一度到八度内的常见音程。
- 发声音域为 MIDI A0-C8，覆盖低音提琴、贝斯、吉他和钢琴常见/完整参考范围。
- 出题时会根据音程方向调整根音范围，保证两个音都不会超出 A0-C8。

## 和声听辨

- 系统随机生成根音和和弦性质。
- 多个音同时播放。
- 用户识别和弦性质。
- 首版显示正确答案时包含根音，但答题重点是和弦性质。
- 和弦根音会按和弦最高构成音动态限制，保证所有和弦音都处于 A0-C8。

## 当前限制

- 使用合成音色；滤波会随音高调整，以避免 A0-C8 边界音被明显削弱。
- 不做真实乐器采样。
- 不识别用户演奏输入。
