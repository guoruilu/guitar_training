# 指板训练设计

琶音训练和音阶训练共用同一套指板交互组件。

## 点选找音

给出一个目标，例如 `Cmaj7` 或 `A 小调五声音阶`，并随机指定一个连续品位范围。用户在范围内选择目标音集合。判定标准是：

- 不选择范围内的目标外音。
- 找出本题范围内所有目标音位置。
- 范围外位置禁用，不参与判题。

## 逐题定位

给出目标中的一个音级和音名，例如 `b3 / Eb`。用户在指板上选择一个正确位置。

逐题定位也限制在本题随机品位范围内；目标音级会优先从该范围中实际存在的位置里抽取。

## 路线练习

给出目标音级顺序，例如 `R - 3 - 5 - 7`。用户按顺序选择对应位置。

路线练习限制在本题随机品位范围内完成。

## 当前默认

- 标准调弦：`E A D G B E`。
- 默认显示空弦和 `1-12` 品；空弦以独立列呈现，不作为 `0` 品显示在主指板里。
- 可切换音名和音级显示。
- 每题随机指定连续 4 个品位作为可作答范围，例如 `5-8品`。
- 可切换图表视角和 `3D 第一人称演奏视角`；3D 视角支持鼠标拖拽旋转和滚轮缩放。
- 琴弦顺序可选 `1弦在上` 或 `1弦在下`，默认是 `1弦在上`。

## 上下文音名拼写

目标音显示按当前根音/调和音级拼写，而不是固定使用升号音名。示例：

- `F#7` 按标准属七拼作 `F# A# C# E`。
- `Gb7` 拼作 `Gb Bb Db Fb`。
- 减七、变化音和极端调号允许出现重升/重降，例如 `G#maj7` 的七音为 `F##`，`Gb dim7` 可出现 `Bbb Dbb Fbb`。

实际判题仍按 pitch class 判断，音名拼写只影响显示和提示。

## 随机出题池

琶音和音阶页都有 `手动` 和 `随机` 出题方式：

- 手动：用户固定选择根音/调和类型，下一题只重新随机指板范围。
- 随机：系统从用户勾选的根音/调池和当前模块的类型池中抽题。
- 根音/调池包含自然音、升号、降号和少量等音拼写，例如 `E#`、`Fb`、`B#`、`Cb`。
- 琶音页可单独勾选随机和弦池；默认包含 `7`、`maj7`、`m7`、`m7b5`、`dim7`。
- 随机和弦池、根音/调池在控制栏中默认以折叠面板呈现，标题显示当前已选数量，展开后可继续勾选或全选。

## 3D 第一人称方向标识

3D 第一人称指板在琴头端显示琴枕、调音钮和 `琴头` 标签，画布上下边缘显示 `琴头端` / `琴身端` 标签，用于区分头端和身体端。

默认 3D 第一人称视角把 6 弦放在更接近镜头的一侧。切换全局琴弦顺序时，3D 近侧/远侧也会随之翻转。

## 当前题库范围

琶音题库覆盖三和弦、挂留、六和弦、七和弦、九/十一/十三扩展和弦、半减/减七、变化属七、`maj7#11` 等常见爵士练习类型。

音阶题库覆盖大调、自然/和声/旋律小调、五声、布鲁斯、教会调式、Lydian dominant、altered、全音、半全/全半减音阶、bebop 和常见变化属音阶。
