# 指板训练设计

琶音训练和音阶训练共用同一套指板交互组件。

## 点选找音

给出一个目标，例如 `Cmaj7` 或 `A 小调五声音阶`，并随机指定一个连续品位范围。用户在范围内选择目标音集合。判定标准是：

- 不选择范围内的目标外音。
- 找出本题范围内所有目标音位置。
- 范围外位置禁用，不参与判题。

## 逐题定位

给出目标中的一个音级和音名，例如 `b3 / Eb`。用户在指板上选择一个正确位置。

逐题定位也限制在本题随机品位范围内；目标音级会优先从该范围中实际存在的位置里抽取。

## 路线练习

给出目标音级顺序，例如 `R - 3 - 5 - 7`。用户按顺序选择对应位置。

路线练习限制在本题随机品位范围内完成。

## 当前默认

- 标准调弦：`E A D G B E`。
- 默认显示空弦和 `1-12` 品；空弦以独立列呈现，不作为 `0` 品显示在主指板里。
- 可切换音名和音级显示。
- 每题随机指定连续 4 个品位作为可作答范围，例如 `5-8品`。
