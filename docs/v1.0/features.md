# v1.0 功能说明

## 主界面

应用主界面由顶部导航、左侧设置/统计栏和右侧训练工作区组成。

顶部导航：

- `听力训练`：进入音程与和声听辨。
- `琶音训练`：进入指板琶音练习。
- `音阶训练`：进入指板音阶练习。
- `说明`：打开使用说明弹窗。

左侧设置：

- 本地统计：汇总所有训练模块的正确率、总正确数、总次数和最佳连续正确。
- 指板设置：品位数量、二维/三维视角、琴弦顺序、是否显示音名、是否显示音级。
- 外观：暗色/明色主题。
- 数据管理：重置、导出、导入本地进度。

## 听力训练

听力训练分为音程和和声两个 tab。

### 音程听力

训练流程：

1. 根据用户选择的音域、音程池和方向生成题目。
2. 用户点击 `重播` 播放当前题。
3. 用户在候选按钮中选择音程答案。
4. 系统标记正确答案并记录统计。
5. 用户点击 `下一题` 生成新题并自动播放。

可配置项：

- 听力最低音和最高音。
- 音程方向：随机上下行、上行、下行。
- 训练音程池：P1 到 P8 的全部常用音程，可全选，至少保留一个。

校验逻辑：

- 只校验用户选择的音程 id 是否等于题目音程 id。
- 答题后本题锁定，避免重复记录。

### 和声听力

训练流程：

1. 在当前音域内随机根音和和弦性质。
2. 播放同时发声的和弦音。
3. 用户选择和弦性质。
4. 系统显示正确和弦标签并记录统计。

和弦题库：

- 大三、小三、减三、增三、挂留、六、加九、七、九、十一、十三和变化属七等和弦性质。
- 数据来自 `CHORD_QUALITIES`。

## 指板琶音训练

琶音训练使用和弦性质作为目标公式。每道题包含：

- 根音。
- 和弦类型。
- 目标音级和音名。
- 随机品位范围。
- 练习模式。

出题方式：

- 手动：用户选择根音和和弦类型。
- 随机：系统从启用的根音池和和弦池中抽取。

随机和弦池：

- 默认包含属七、大七、小七、半减七、减七。
- 用户可以展开 `选择和弦` 面板调整。
- 至少保留一个和弦，避免空题库。

## 指板音阶训练

音阶训练使用音阶定义作为目标公式。每道题包含：

- 调/根音。
- 音阶类型。
- 目标音级和音名。
- 随机品位范围。
- 练习模式。

音阶题库包括：

- 大调、自然小调、和声小调、旋律小调。
- 大/小五声音阶、布鲁斯音阶。
- 七个教会调式。
- altered、whole-tone、diminished、bebop 等常用爵士/现代音阶。

随机调性池：

- 用户可以展开 `选择根音 / 调` 面板调整。
- 支持升降号同音异名根音，例如 `C#` 和 `Db`。
- 至少保留一个根音。

## 三种指板练习模式

### 点选找音

目标：找出当前品位范围内所有属于目标公式的指板位置。

系统判断：

- 选中的所有位置必须都是目标位置。
- 当前品位范围内的所有目标位置都必须被选中。
- 错误时反馈缺少的位置和误选的位置。

### 逐题定位

目标：只找一个指定音级/音名。

系统判断：

- 必须只选择一个位置。
- 该位置的 pitch class 必须等于当前 focus pitch class。

### 路线练习

目标：按照公式顺序依次点选目标音。

系统判断：

- 选择数量必须等于目标公式音数。
- 每个选择位置的 pitch class 必须按顺序匹配目标 pitch class。

## 二维指板

二维指板用于清晰、密集地显示所有弦和品位：

- 支持 12、15、17 品。
- 支持空弦。
- 支持图表视角和第一人称左右翻转。
- 可按用户设置调整 1 弦在上或在下。
- 已选位置、正确目标、错误位置通过 CSS class 区分。

## 三维第一人称指板

三维指板用于更接近演奏者视角的训练：

- 使用 Three.js 渲染。
- 默认 6 弦更接近镜头。
- 场景中有琴头、nut、弦钮、品丝、品记和琴弦。
- 屏幕固定标签显示 `琴头端` 和 `琴身端`。
- 支持拖拽旋转观察。
- 点击 marker 可作答，拖拽不会误触。

## 数据导入导出

导出：

- 将当前 `UserProgress` 序列化为 JSON。
- 文件名固定为 `guitar-training-progress.json`。

导入：

- 读取 JSON。
- `normalizeProgress` 校验版本、设置和统计。
- 缺失字段使用默认值补齐。
- 非法字段回落到安全默认值。

## 桌面运行

Electron 桌面壳：

- 加载 `web/dist/index.html`。
- 打包后从 Electron resources 中加载 `web-dist`。
- 禁用 Node integration。
- 启用 sandbox 和 context isolation。
- 阻止主窗口导航到外部 URL，外链交给系统浏览器。
- 设置 `userData` 到 `Guitar Training`，让 localStorage 数据跟随产品名保存。
